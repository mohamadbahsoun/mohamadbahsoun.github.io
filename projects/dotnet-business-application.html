Demonstration / Reference Application

C# / .NET Business Application

A business request and approval application designed to demonstrate C#/.NET development, SQL Server integration, role-based access, business workflows and REST API integration.

Project Overview

The application provides a centralized way for employees to submit business requests and for authorized users to review, approve or reject those requests.

Business Scenario

Employees currently submit requests through email or disconnected processes. The organization wants a centralized application to manage requests and approvals.

Business Objective

Provide a simple application where requests can be submitted, tracked and processed according to defined business roles.

Application Users

Employees, managers and administrators, with each role receiving the functionality required for their responsibilities.

Core Platform

C# / .NET application with SQL Server as the primary relational database.

Application Architecture

The application separates the presentation, business logic and data-access responsibilities to make the solution easier to maintain and extend.

Business Workflow

The application follows a simple request lifecycle.

1

Submit Request

An employee creates a new request and provides the required information.

2

Validation

The application validates required fields and applies the appropriate business rules.

3

Manager Review

The request is presented to the appropriate manager for review.

4

Approval or Rejection

The authorized approver can approve or reject the request and provide comments.

5

Status Tracking

The requester can view the current status and history of submitted requests.

Application Features

The application includes common functionality required by internal business systems.

  • User authentication
  • Role-based authorization
  • Request submission
  • Request editing
  • Request status tracking
  • Approval workflow
  • Rejection with comments
  • Request history
  • Search and filtering
  • Dashboard information
  • Audit records
  • REST API integration

Role-Based Access

Employee

Submit requests, view personal requests and monitor request status.

Manager

Review requests assigned to the manager and approve or reject them.

Administrator

Manage application configuration, users, roles and system information.

Auditor

Review historical request activity and audit information where required.

REST API

A REST API provides a controlled interface for external applications and integrations to interact with the business application.

Request API

Create, retrieve and update business requests through defined API endpoints.

Approval API

Provide controlled operations for approval and rejection processes.

Authentication

API access should be protected using an appropriate authentication and authorization mechanism.

Integration

External systems can consume approved endpoints without directly accessing the database.
