Project overview

A practical approach to planning a migration from a legacy SharePoint 2013 environment to a modern SharePoint Subscription Edition environment.

Migration planning noteA migration should begin with an assessment of the existing environment and the supported migration path. The exact approach depends on the source version, target version, customizations, databases, integrations and business requirements.

Environment assessment

Before migration, the existing farm is documented and analyzed to find dependencies that could affect the migration or require remediation.

    Migration strategy

    The migration is treated as a controlled project rather than a simple server replacement.

    SQL Server considerations

    SQL Server is a critical part of a SharePoint farm, so planning includes database discovery, capacity, backup strategy and validation.

    Application & workflow dependencies

    Migration planning must account for components outside the standard SharePoint platform.
